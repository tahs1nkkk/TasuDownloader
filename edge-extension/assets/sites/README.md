# Bundled site marks

These are site identity assets, not downloadable media. They are bundled locally:
opening the popup never requests a favicon from a site or a third-party service.
Brand ownership remains with the respective sites. Retrieved 2026-09-05.

RedGifs, Scrolller and Instagram URLs were discovered in their current
home-page icon declarations. Coomer's own page metadata links its shared Kemono
fox mark; this vector replaces the site's blurry 32px favicon. Its external DTD
declaration was removed; the vector paths and colors are unchanged.
Reddit's current declared 64px icon has a 192px
variant at the same official asset location. OnlyFans blocks the home-page
metadata request; its last accessible official CDN touch icon is used (the URL
contains a 2025 build revision; current home-page branding was not verified).
The separate menu-icons.svg sprite is original extension artwork.
